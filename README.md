# Сайт MONO — студии лазерной эпиляции

Статический сайт: быстро грузится, хорошо индексируется Яндексом, работает на любом хостинге (включая Спринтхост) без PHP и баз данных.

## Как поменять данные

Всё содержимое лежит в **`data/site.json`**: адреса, телефоны, часы, координаты, Instagram, прайсы, вопросы-ответы.
Поменяли → запустили сборку → загрузили папку `dist/` на хостинг.

```bash
node build.js
```

Сборка напишет, сколько заглушек `TODO` ещё осталось.

| Поле | Что это |
|---|---|
| `domain` | Адрес сайта, например `https://mono-laser.ru` (нужен для sitemap и canonical) |
| `address`, `metro`, `directions` | Адрес и подсказка, как пройти |
| `lat`, `lon` | Координаты входа: правый клик по точке в Яндекс Картах → «Что здесь?» |
| `yandex_org_id` | Номер карточки в Яндекс Картах: цифры из ссылки `yandex.ru/maps/org/mono/`**`1234567890`**`/`. Когда номер указан, на сайте появятся настоящие отзывы и карта с карточкой |
| `photos` | Фото студии: положите файлы в `src/assets/img/<город>/` и перечислите их: `[{"file": "1.webp", "alt": "Кабинет MONO в Нальчике"}]`. Первое фото будет крупным |
| `yandex_metrika_id` | Номер счётчика Метрики. Цели `booking_click`, `phone_click` и `route_click` отправляются автоматически |
| `yandex_verification` | Код из Яндекс Вебмастера для подтверждения прав на сайт |

## Как выложить на Спринтхост

1. В панели Спринтхоста привяжите домен к сайту и включите бесплатный SSL (Let's Encrypt).
2. Через файловый менеджер или FTP загрузите **содержимое** папки `dist/` (не саму папку) в корень сайта (обычно `domains/<домен>/public_html`).
3. Проверьте, что загрузился файл `.htaccess`: он включает HTTPS, сжатие и кэширование.

Вариант с GitHub: храните проект в репозитории, а для выкладки используйте GitHub Actions + FTP (`SamKirkland/FTP-Deploy-Action`). Доступ по FTP берётся из панели Спринтхоста и сохраняется в Secrets репозитория.

## Структура

```
data/site.json        ← все данные
build.js              ← сборщик (Node 18+, без зависимостей)
src/assets/           ← стили, скрипты, шрифты, картинки
src/htaccess.txt      ← настройки Apache
dist/                 ← готовый сайт для загрузки
```

Страницы: `/` (выбор города), `/moskva/`, `/nalchik/`, `/kaspiysk/`, `/vladikavkaz/`, плюс `sitemap.xml`, `robots.txt` и `404.html`.

## Что уже сделано для SEO

- Отдельная страница под каждый город с запросом «лазерная эпиляция в <городе>» в title и H1.
- Разметка Schema.org: `BeautySalon` с адресом, координатами, часами работы и полным прайсом, а также `FAQPage` и хлебные крошки.
- `sitemap.xml`, `robots.txt`, canonical, Open Graph с картинкой для соцсетей и мессенджеров.
- Шрифты лежат на самом сайте, без Google Fonts, поэтому страницы быстро открываются из России. На мобильных есть панель «Позвонить / Маршрут / Записаться».
